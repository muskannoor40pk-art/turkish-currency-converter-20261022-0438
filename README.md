### Overview
The Currency Converter (Turkish Edition) is a sleek, single-file web utility designed for users who need quick, reliable currency calculations without the complexity of external API dependencies. Tailored specifically for Turkish users, it features a clean interface, intuitive controls, and a focus on local currency pairs.

### ✨ Features
*   **Swap Functionality:** Instantly toggle between source and target currencies with a single click.
*   **Popular Currencies:** Pre-configured with the most relevant currencies for the Turkish market (TRY, USD, EUR, GBP, etc.).
*   **Offline-Ready Demo Rates:** Built-in exchange rate logic that functions immediately without requiring API keys or internet-based data fetching.
*   **Responsive Design:** Optimized for both desktop and mobile devices using modern CSS Flexbox and Grid.
*   **Zero-Dependency:** Pure Vanilla JavaScript implementation for maximum speed and security.

### 🌍 Localization Notes
*   **Language:** The interface is localized for Turkish users.
*   **Formatting:** Follows Turkish number formatting conventions (using commas as decimal separators where applicable).
*   **Directionality:** Optimized for LTR (Left-to-Right) layout, standard for the Turkish language.

### 🛠 Tech Stack
*   **Markup:** HTML5
*   **Styling:** Modern CSS (Flexbox/Grid)
*   **Logic:** Vanilla JavaScript (ES6+)
*   **Hosting:** GitHub Pages
